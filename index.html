Berechnung

Ort und Koordinaten lassen sich über den Ortsnamen in der Titelzeile ändern.

Die angenommene Höhe über dem Gelände beträgt 5 m; passe sie an die Dachhöhe an. Sonstige Verluste 12 %, Albedo 0,2. Nahverschattung wird nur mit gültiger nahverschattung.json aktiv; ohne diese gilt die Prognose als unvollständig. Bei einer Änderung der Dachhöhe wird für diese Einstellung einmalig ein neues Profil benötigt.

Ohne Installation: läuft auf GitHub Pages in Safari/anderen Browsern. Wetter: Open-Meteo; bei Ausfall eigenständiger DWD-MOSMIX-L-Abruf über GitHub Actions. DWD liefert stündliche Globalstrahlung, Direkteinstrahlung und Diffusstrahlung werden dabei nur näherungsweise nach Erbs abgeleitet. Keine gleichwertige 15-Minuten-Strahlungsauflösung. Gelände: Mapzen Terrain Tiles über AWS Open Data (Quellen u. a. SRTM; meist ca. 30 m echte Geländeauflösung, regional unterschiedlich). Bei jeder Wetteraktualisierung wird dein eingestellter Standort an Open-Meteo übertragen. Geländekacheln werden für jede neue Standort-/Höhenkombination höchstens einmal automatisch abgefragt; danach nur noch auf ausdrücklichen Wunsch. Erfolgreiche Profile werden pro Browser lokal gespeichert. Das Horizontdiagramm ist dauerhaft schreibgeschützt. Eine exportierte horizontprofil.json kann für alle Geräte auf GitHub Pages hinterlegt werden. Je Tag werden eine ursprüngliche Vergleichskurve und der fortgeschriebene aktuelle Stand im Browser gespeichert, nicht über GitHub synchronisiert. Safari im privaten Modus kann sie beim Schließen löschen; ohne geöffneten Browser gibt es keine garantierten Vorabend-Aufnahmen. Browserdaten können gelöscht werden. V12 erfordert die passende DOM20-basierte nahverschattung.json. Vorherige V10-Archivdateien werden nicht verändert. Die Vereinfachung behandelt Bäume und Gebäude als lichtundurchlässige Geometrie und berücksichtigt keine zusätzlichen elektrischen Teilverschattungsverluste. Keine Gewähr für tatsächliche Erträge.
